### Projeto: Gerenciador de reservas de salas de aula

## Descrição da funcionalidade: Cadastro de salas de aula

Este arquivo detalhará as funcionalidades de cadastro de sala de aula na aplicação. Todos os demais padrões citados anteriormente deverão ser seguidos para o desenvolvimento desta funcionalidade.

## Lista de requisitos

 - Todas as funcionalidades relacionadas ao cadastro de salas de aula deverão ser apenas disponíveis para os usuários do tipo 1 - administrador.
 - O cadastro de salas de aula deverão conter os campos de nome da sala, localização, tipo de sala (Laboratório ou sala de aula).
 - O cadastro de salas de aula também deverá contar com a opção de anexar uma imagem da sala a ser cadastrada para ser apresentada na listagem das salas.
 - Deverá ser possível atualizar os dados de uma sala ja cadastrada no sistema, permitindo a mudança das informações cadastradas no sistema.
 - Deverá ser possível remover uma sala de aula do sistema, porém apenas se for definido que não exista nenhuma reserva ativa para esta sala no momento da remoção.
