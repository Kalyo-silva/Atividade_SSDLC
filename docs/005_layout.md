### Projeto: Gerenciador de reservas de salas de aula

## Descrição da funcionalidade: Layout da aplicação

Este arquivo detalhará o layout da aplicação. Todos os demais padrões citados anteriormente deverão ser seguidos para o desenvolvimento desta funcionalidade.

## Layout

 - Ao acessar o sistema, o formulário de login deverá ser a primeira coisa a ser apresentada ao usuário. qualquer acesso a outras páginas da aplicação é proibida caso o login não seja realizado.
 - Após o login ser realizado, o usuário ira ser direcionado para uma de duas telas principais, dependendo do tipo de usuário que foi logado.
 - para os usuários do tipo 1 - Administrador, a aplicação será direcionada para um painel administrativo, contendo informações sobre o numero de salas cadastradas, o numero de reservas que estão cadastradas e o número de salas reservadas para o dia atual. Nesta tela, o administrador também contará com um menu contendo apenas as seguintes funcionalidades: Cadastro de usuários e Cadastro de salas de aula.
 - Para a tela de cadastro de usuários, deverá ser disponibilizado uma listagem de todos os usuários cadastrados no sistema, permitindo que o administrador atualize informações realacionadas a conta, bem como realize o cadastro de novos usuários, conforme detalhado no arquivo de descrição das funcionalidades do cadastro de usuários.
 - Para a tela de cadastro de salas de aula, deverá ser disponibilizado uma listagem de todas as salas cadastradas no sistema, permitindo que o administrador atualize informações relacionadas as salas, bem como realize o cadastro de novas salas de aula, conforme detalhado no arquivo de descrição das funcionalidades do cadastro de salas de aula.
 - Para os usuários do tipo 2 - Professor, após o login a aplicação irá direcionar o usuário para a lista de salas cadastradas, onde o mesmo poderá realizar a seleção da sala desejada para a reserva, conforme detalhado no arquivo de descrição das funcionalidades da reserva de salas.
 - O usuário do tipo 2 - professor devera possuir um menu que contenha apenas as seguinte funções: salas de aula e minhas reservas.
 - Na tela de minhas reservas o usuário professor deverá vizualizar as reservas que foram feitas pelo seu usuário, bem como podendo alterar ou cancelar reservas realizadas
 - no menu de ambos os tipos de usuário também deverá existir um botão para realizar o logout da aplicação.
